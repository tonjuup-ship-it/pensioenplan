              Data & instellingen

              Eén keer per maand, één minuut

              Sleep je nieuwste exports hierheen. Het dashboard leest ze, slaat over wat er al in staat en rekent alles opnieuw uit. Koersen worden automatisch bijgewerkt als je het dashboard opent.

              Welkom bij je nieuwe dashboard

              Upload hieronder je exports van Degiro en Revolut. Daarna staat alles klaar.

              Exports uploaden

              Degiro: Rekeningoverzicht en Transacties (CSV) · Revolut: rekeningafschrift (PDF)

                Waar vind ik deze exports?
                1. Degiro rekeningoverzicht: Inbox → Rekeningoverzicht → periode vanaf je eerste storting → Exporteren → CSV.
                2. Degiro transacties: Inbox → Transacties → zelfde periode → Exporteren → CSV.
                3. Revolut: app → Beleggen → ··· → Documenten → Rekeningafschrift → PDF, volledige periode.
                4. Volgende keer is de laatste maand genoeg: overlap is geen probleem.
